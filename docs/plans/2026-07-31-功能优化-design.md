# 时间手账功能优化设计

日期：2026-07-31
状态：已确认

## 背景

月视图时间手账（React + FastAPI + Supabase）已完成基础功能：月视图日历、记录增删改、分类管理、Excel 导入、多账户登录。现根据用户反馈优化三大方向：**记录更快、数据统计、界面体验**。

## 用户核心反馈

- 添加记录点击路径过长：主类下拉 → 选择 → 次类下拉 → 选择
- 需要月度图表、周报/汇总、年度热力图
- 不想要 emoji 图标，显得不专业，换成线条图标
- 交互细节：日历点日期就地编辑，不跳页

## 一、记录更快

### 1.1 添加页按钮化
- 主类改为 7 个大按钮网格，点击选中高亮
- 次类跟随主类变为按钮网格，点击完成分类
- 日期默认今天、时间默认当前时刻
- 记住上次的主类/次类/时间段（localStorage）

### 1.2 首页常用活动一键记录
- 首页顶部"快捷记录"栏，展示最近常用的 4-6 个活动（主类-次类组合）
- 点击 = 直接记录一条 1 小时记录（默认时长可配置）
- 自动根据使用频率更新（统计最近 N 条记录中最高频组合）
- 记录成功有轻提示 + 页面刷新

### 1.3 分类选择交互
- 主类/次类按钮支持再次点击取消
- 常用活动按钮长按/设置可调时长（本期先固定 1 小时，后续可配）

## 二、数据统计（新增「统计」页）

### 2.1 路由与导航
- 新增路由 `/stats`，底部导航加第 5 项「统计」
- 后端新增 `GET /api/entries/year?year=` 接口（全年数据，热力图用）

### 2.2 月度图表
- 当月分类占比环形图（top5 + 其他）
- 每日时长柱状图
- 月份切换器复用月视图逻辑

### 2.3 周报/汇总
- 本周总时长、活跃天数、日均时长
- 分类时长排行（top5）
- 与上周对比（总时长涨跌幅）
- 计算方式：前端用月度接口数据汇总

### 2.4 年度热力图
- 全年 365 色块（周行排列，GitHub 风格）
- 颜色深浅 = 当天总时长（5 档色阶）
- 点击某天弹出当日明细
- 月份标签（1月-12月）

## 三、界面体验

### 3.1 去 emoji，换专业图标
- 引入 `lucide-react`
- 替换位置：顶部标题、底部导航（月视图/记录/类别/导入/统计）、侧边导航、登录页、各类按钮
- 统一线条风格，16-20px

### 3.2 视觉规范
- 统一卡片：圆角 12px、细边框、轻阴影
- 间距规范化（4 倍数体系）
- 主色保持 indigo (#6366f1)，加深浅两档
- 字体层级：标题/正文/辅助三级

### 3.3 交互细节
- 月视图点击日期 → 弹底部抽屉（移动端）/弹窗（桌面），显示当天记录列表
- 抽屉内可编辑/删除，不跳页
- 删除有二次确认

## 技术实现

| 项 | 选型 | 说明 |
|----|------|------|
| 图标 | lucide-react | 专业线条图标，轻量 |
| 图表 | recharts | React 生态，支持环形图/柱状图 |
| 后端接口 | GET /api/entries/year | 全年数据（热力图） |
| 快捷记录 | 前端 localStorage + 月度数据统计 | 无新接口 |
| 状态管理 | React useState + props | 保持简单，不引入 Redux |

## 不做的事（YAGNI）

- 不做完整登录注册页（账号由服务器预置）
- 不做语音记录（本期）
- 不做桌面小组件/PWA 安装（本期）
- 不做自定义主题色（本期保留默认主色）

## 验收标准

1. 添加记录：主类+次类各点一下完成，总点击 ≤ 3 次（不含提交）
2. 首页一键记录：点一下出现成功提示，数据在月视图可见
3. 统计页：月度图表/周报/热力图数据与月视图一致
4. 界面无 emoji，图标风格统一
5. 移动端（375px）和桌面端均正常
